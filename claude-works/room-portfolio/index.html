About

わたしについて

森田 結（もりた ゆい）Frontend Engineer / UI Designer

「作ったもので誰かが少し笑ってくれたら嬉しい」をモットーに、Web制作をしています。 普段は React や Tailwind CSS を使ったUI実装が中心ですが、素のHTML/CSS/JSで 手を動かすのも好きで、休日はドット絵素材を組み合わせて遊んでいます。

小さな会社のコーポレートサイトから、個人向けのLP・ツール制作まで幅広く対応します。 「ちょっと遊び心のあるサイトにしたい」というご相談、大歓迎です。

  • 🏠拠点：日本（フルリモート対応）
  • 🎓独学 → 制作会社勤務を経てフリーランスへ
  • ☕好きなもの：珈琲、観葉植物、レトロゲームのドット絵
